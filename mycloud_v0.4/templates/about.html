About myCloud

myCloud is a personal cloud storage application designed to provide a secure and intuitive platform for managing your files. This project was developed as a learning exercise to explore full-stack web development.

Development started on August 8th, 2025. The project was created by me, a first-year student at VIT, Tamil Nadu, during my first month of my first semester. This project, as of August 26, 2025, is a demonstration of the skills I've acquired.

Key Features

Security

Secure user registration with email verification and password policies.

Integration

Social login integration with Google and GitHub.

File Management

Upload, download, rename, and preview common formats (images, videos, PDFs).

Smart Search

Live, asynchronous search for instantaneous file access.

Stash

A temporary storage area for sharing files with expiry.

Technology Stack

Python (Flask) MySQL HTML5 / CSS3 Vanilla JS Authlib
